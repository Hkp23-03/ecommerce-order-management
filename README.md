# E-Commerce Order Management System

## Project Description
This project is a menu-driven E-Commerce Order Management System developed using Java, JDBC and MySQL.

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Features
1. Insert order records.
2. Display orders based on status and quantity.
3. Increase order quantity.
4. Update order status with validation.
5. Calculate total order value.
6. Delete orders only when their status is Cancelled.

## Database
Database Name: ecommerce_db

Table Name: Orders

## How to Run
1. Create the ecommerce_db database in MySQL.
2. Create the Orders table.
3. Configure MySQL credentials in the Java application.
4. Add the MySQL JDBC driver.
5. Run Main.java in IntelliJ IDEA.
